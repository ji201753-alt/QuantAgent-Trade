# Quant Intelligence Workstation

An institutional-grade, local-first quantitative market intelligence and operational investigation workstation focused on market microstructure, probabilistic forecasting, and ecosystem cognition.

## 🚀 Overview

The workstation is a production-grade environment designed for high-fidelity market intelligence. It transforms raw ingestion into contextual cognition through a multi-layered quantitative core, providing operators with immersive situational awareness and forensic investigation tools.

### Core Intelligence Systems
- **Real-time Ingestion**: Resilient WebSocket-based ingestion for Polymarket CLOB, featuring exponential backoff, sequence tracking, and normalized universal schemas.
- **Microstructure Analytics**: Real-time engines for orderbook imbalance, liquidity concentration, volatility spikes, and market pressure velocity.
- **Forecasting (TimesFM)**: Probabilistic multi-horizon forecasting integrated as a lazy-loading modular component.
- **Macro Intelligence**: Synthesis of macroeconomic calendars, news catalysts, and external volatility indices into structured operational context.
- **Unified Chronology**: A persistent, synchronized timeline of all operational events (anomalies, signals, catalysts) across the entire ecosystem.
- **Signal Intelligence**: Uncertainty-aware signal fusion combining microstructure, forecasts, and macro-regimes with Bayesian weight calibration.
- **Contextual Cognition**: High-level synthesis of market structure into explainable operational regimes, situational summaries, and automated event correlation.
- **Market Memory**: Persistent historical cognition using contextual fingerprinting, structural similarity retrieval, and historical analog discovery.
- **Decision Intelligence**: Modeling of structural confidence, consensus coherence (agreement between analytical systems), and structural fragility.
- **Grounded Reasoning**: LLM-assisted investigation co-pilot strictly grounded in quantified intelligence and ecosystem chronology.

## 🖥 Workstation UX & Investigation

The workstation features a cinematic, institutional-grade UI designed for deep immersion and forensic analysis.

- **Forensic Workspaces**:
    - **Real-time Monitor**: High-frequency flow monitoring and immediate signal intelligence.
    - **Comparison Workbench**: Side-by-side structural analysis of live market states vs. historical analogs.
    - **Ecosystem Intelligence**: Systemic overview of cross-market contagion, liquidity migration, and structural propagation.
    - **Operational Investigation**: Forensic workspace for building structured evidence chains and investigation trees.
- **Cinematic Immersion**:
    - **Reactive Motion**: The UI "breathes" with market volatility; instability triggers subconscious visual feedback (edge glows, color shifts).
    - **Contextual Ripple System**: Interacting with one panel ripples contextual awareness across the entire workspace.
- **Investigation Workflows**: Persistent case management supporting parent/child forensic branching, catalyst linking, and professional investigation exports.
- **Deterministic Replay**: Traverse historical market structure with cinematic fidelity, synchronized across all analytical layers.

## 🛡 Operational Philosophy

- **Local-First**: All data, intelligence, memory, and models are persisted and executed locally. Zero cloud dependency.
- **Probabilistic**: Focus on uncertainty, reliability, and situational pressure to support human decision-making.
- **Grounded**: Reasoning components are strictly restricted to synthesizing existing quantified intelligence—no hallucinated autonomous decisions.

## ⚙️ Getting Started

### Prerequisites
- Python 3.12+
- Node.js v22+
- TA-Lib

### Installation
1. Install Python dependencies: `pip install -r requirements.txt`
2. Install Frontend dependencies: `cd frontend && npm install`

### Execution
1. Start the Quantitative Core: `python -m core.engine`
2. Start the Terminal: `cd frontend && npm run dev`
