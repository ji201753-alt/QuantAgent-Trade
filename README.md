# Quant Intelligence Workstation (v1.5)

A converged market intelligence operating system designed for real-time multi-domain cognition, forensic investigation, and ecosystem monitoring.

## 🚀 The Adaptive Operational Surface

The workstation transforms complex multi-market microstructure into a unified, compositionally adaptive control surface.

### Multi-Domain Workspaces
- **Prediction Markets**: Specialized environment for Polymarket-style monitoring with layered probability charts and whale pressure tracking.
- **Arbitrage Surface**: Real-time geopolitical liquidity surface with regional spread topology and capital flow analysis.
- **Crypto Intelligence**: Synchronized multi-asset monitor with funding pressure and exchange divergence tracking.
- **Forensic Chronology**: Automatically reconstructed investigative narratives and evidence chains.
- **System Diagnostics**: Professional runtime observability for model inference, memory indexing, and ingestion health.

### Investigative Tooling
- **Investigation Builder**: Create persistent forensic workspaces with replay anchors, analog comparisons, and publication-ready reports.
- **Kronos Structural Cognition**: Visual discovery and side-by-side comparison of historical analogs directly in the chart timeline.
- **TimesFM Projections**: Probabilistic forecasting with confidence gradients and accuracy drift diagnostics.
- **Ecosystem Propagation**: Systemic tracking of structural contagion across correlated market domains.

## 🧠 Intelligence Runtime (Local-First)

The workstation orchestrates advanced quantitative models locally for complete analytical continuity:

### Local Model Installation
1. **TimesFM**:
   - Clone `google-research/timesfm` into `forecasting/timesfm/src/`.
   - Install dependencies: `pip install -e .`.
   - Place weights in `checkpoints/timesfm-1.0-200m/`.
2. **Hardware Acceleration**: Automatic CUDA detection with seamless CPU fallback.
3. **Diagnostics**: Real-time monitoring of inference latency and GPU utilization in the Diagnostics workspace.

## 🛠 Platform Architecture

- `/core`: Extensible registry orchestration and system-wide health monitoring.
- `/connectors`: Resilient adapters for Binance, Polymarket, Bybit, OKX, and future domains.
- `/analytics`: Real-time microstructure synthesis and anomaly clustering.
- `/investigations`: Forensic case management, archival, and reporting.
- `/reasoning`: Grounded briefings and the persistent Operational Copilot.
- `/frontend`: Adaptive cinematic terminal workstation (v1.5 Operational OS).

## ⚙️ Quick Start

1. **Environment**: Run `./install.sh`.
2. **Configure**: Edit `config/settings.yaml` to enable model runtimes.
3. **Launch Engine**: `python -m core.engine`.
4. **Launch Terminal**: `cd frontend && npm run dev`.
